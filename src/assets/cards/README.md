# Card images

Drop card pictures here and they appear in **Codex → All cards (text)** on the next build.

- Name the file after the card's id, e.g. `hans_the_butcher_death_blow.png`.
  In the app, tick **Show image slots** to see the exact file name under each card.
- If the same card appears in several boxes with different printings, prefix the
  owner id with a double underscore: `camp_happy_trails__aluminum_bat.png`.
- Final Girl cards use the Final Girl id, e.g. `laurie_carpenter.png`.
- `.png`, `.jpg`, `.jpeg` and `.webp` all work.
